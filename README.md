# CHART Evidence Atlas

A static, dependency-free scientific microsite about rezvilutamide in high-volume mHSPC. Open `index.html` locally or serve the directory on any static host, including GitHub Pages. The 3D anatomy is procedurally generated with WebGL and has an inline SVG fallback.

## Clinical source record

- Gu et al., *The Lancet Oncology* (2022), DOI: [10.1016/S1470-2045(22)00507-1](https://doi.org/10.1016/S1470-2045(22)00507-1). Primary CHART report; 2022 interim OS HR 0.58 (95% CI 0.44–0.77), with median OS not reached in both arms.
- Ye et al., *Journal of Clinical Oncology* 44, abstract 5090 (2026), DOI: [10.1200/JCO.2026.44.16_suppl.5090](https://ascopubs.org/doi/10.1200/JCO.2026.44.16_suppl.5090). Five-year update; median OS 78.8 vs 44.8 months, HR 0.59 (95% CI 0.47–0.73), data cutoff 6 June 2025.
- Armstrong et al., *European Urology* (2026), [ARCHES five-year post hoc update](https://pubmed.ncbi.nlm.nih.gov/41633900/): five-year OS probability 66% vs 53%; HR 0.70 (95% CI 0.58–0.85). Median OS not reached in either arm.
- Chi et al., *Journal of Clinical Oncology* (2021), [TITAN final analysis](https://ascopubs.org/doi/abs/10.1200/JCO.20.03488): median OS not reached vs 52.2 months; HR 0.65 (95% CI 0.53–0.79).
- Smith et al., *New England Journal of Medicine* (2022), [ARASENS](https://pubmed.ncbi.nlm.nih.gov/35179323/): median OS not reached vs 48.9 months; HR 0.68 (95% CI 0.57–0.80), with ADT and docetaxel in both arms.
- Fizazi et al., *The Lancet Oncology* (2019), [LATITUDE final analysis](https://pubmed.ncbi.nlm.nih.gov/30987939/): median OS 53.3 vs 36.5 months; HR 0.66 (95% CI 0.56–0.78).
- [NCT03520478](https://clinicaltrials.gov/study/NCT03520478), study registry.
- [NCI hormone therapy fact sheet](https://www.cancer.gov/types/prostate/prostate-hormone-therapy-fact-sheet), class-level mechanism context.

The 2026 CHART results are a meeting abstract. Each ARPI comparison is within its own randomized trial; cross-trial figures are not efficacy rankings. Bars show reported medians, not reconstructed Kaplan–Meier curves. The anatomical and mechanism visuals are original simplified educational models, not patient imaging or molecular structures.

## Hosting

Publish the five files in this directory at the repository root. In GitHub Pages, select the `main` branch and `/ (root)` folder as the source. No build step, runtime API, API key, paid service, or external asset is required.
