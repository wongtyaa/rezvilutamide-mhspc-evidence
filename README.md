# CHART Evidence Atlas

A static, dependency-free scientific microsite about rezvilutamide in high-volume mHSPC. Open `index.html` locally or serve the directory on any static host, including GitHub Pages. The selected original generated artwork has a subtle automatic perspective rotation with pause, reduced-motion and offscreen controls. This is animated 2D artwork, not a reconstructed 360-degree model.

The CHART study film is stored in this repository as `chart-study-reel.mp4`, with a local poster image and English WebVTT captions. It plays only when requested, so the film does not add to initial page loading. The film includes original artwork, narration and graphics, and summarizes findings from the dated analyses noted in the page's source record.

## Clinical source record

- Gu et al., *The Lancet Oncology* (2022), DOI: [10.1016/S1470-2045(22)00507-1](https://doi.org/10.1016/S1470-2045(22)00507-1). Primary CHART report; 2022 interim OS HR 0.58 (95% CI 0.44–0.77), with median OS not reached in both arms.
- Ye et al., *Journal of Clinical Oncology* 44, abstract 5090 (2026), DOI: [10.1200/JCO.2026.44.16_suppl.5090](https://ascopubs.org/doi/10.1200/JCO.2026.44.16_suppl.5090). Five-year update; median OS 78.8 vs 44.8 months, HR 0.59 (95% CI 0.47–0.73), data cutoff 6 June 2025.
- Armstrong et al., *European Urology* (2026), [ARCHES five-year post hoc update](https://pubmed.ncbi.nlm.nih.gov/41633900/): five-year OS probability 66% vs 53%; HR 0.70 (95% CI 0.58–0.85). Median OS not reached in either arm.
- Chi et al., *Journal of Clinical Oncology* (2021), [TITAN final analysis](https://ascopubs.org/doi/abs/10.1200/JCO.20.03488): median OS not reached vs 52.2 months; HR 0.65 (95% CI 0.53–0.79).
- Smith et al., *New England Journal of Medicine* (2022), [ARASENS](https://pubmed.ncbi.nlm.nih.gov/35179323/): median OS not reached vs 48.9 months; HR 0.68 (95% CI 0.57–0.80), with ADT and docetaxel in both arms.
- Fizazi et al., *The Lancet Oncology* (2019), [LATITUDE final analysis](https://pubmed.ncbi.nlm.nih.gov/30987939/): median OS 53.3 vs 36.5 months; HR 0.66 (95% CI 0.56–0.78).
- [NCT03520478](https://clinicaltrials.gov/study/NCT03520478), study registry.
- [NCI hormone therapy fact sheet](https://www.cancer.gov/types/prostate/prostate-hormone-therapy-fact-sheet), class-level mechanism context.

The 2026 CHART results are a meeting abstract. Each ARPI comparison is within its own randomized trial; cross-trial figures are not efficacy rankings. Bars show reported medians, not reconstructed Kaplan–Meier curves. The anatomical artwork and mechanism illustration are original educational visuals, not patient imaging or molecular structures.

- [ENZAMET eight-year report](https://doi.org/10.1016/j.annonc.2026.07.412): median OS 7.9 vs 5.8 years, HR 0.73 (95% CI 0.63–0.86); eight-year OS 50% vs 40%.
- [ARANOTE label, Table 8](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=1a7cb212-56e4-4b9d-a73d-bfee7fe4735e): final OS median NR in both arms, HR 0.78 (95% CI 0.58–1.05), not statistically significant.

## Hosting

Publish all files in this directory at the repository root. In GitHub Pages, select the `main` branch and `/ (root)` folder as the source. No build step, runtime API, API key, paid service, or external asset is required.
